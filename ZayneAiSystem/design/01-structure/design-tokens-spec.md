# 设计层结构规范：Design Tokens 与参照语言

设计层的不可逆资产有两个：**参照设计语言的选定**（改一次全站重刷）和 **design tokens**
（每个值都被全部页面消费）。结构规范围绕"让任意页面无法长歪"来设计。

## 参照设计语言（临摹不发明）

- 项目启动时选定**一个**成熟设计语言作参照（如 Ant Design、Material、Radix 风格等），
  记录在项目 `docs/design/reference.md`：选了什么、为什么、主要临摹哪些特征。
- 选定是 L5 决策，做一次；此后 agent 是执行者——所有视觉决策向参照对齐，
  **禁止 agent 自行发明新的视觉风格**。
- 换参照 = 全站重刷，属于最高门槛决策，与数据层破坏性变更同级对待。

## Token 文件（唯一取值来源）

- 位置：`src/shared/styles/tokens.(less|css)`，全站唯一，业务样式禁止定义自己的"小抄"。
- 两层结构：**原始层**（调色板、尺寸原值）→ **语义层**（业务只准消费语义层）。

```less
// ---- 原始层（palette，业务代码禁止直接使用）----
@blue-500: #2563eb;
@gray-100: #f3f4f6;

// ---- 语义层（业务唯一入口）----
@color-primary: @blue-500;
@color-bg-subtle: @gray-100;
@color-danger: ...;
@color-text-primary / @color-text-secondary / @color-border: ...;
```

## 刻度（scale）：数量刻意有限

| 类别 | 刻度 | 说明 |
|------|------|------|
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 | 禁止任意数值（13px、19px 一律非法） |
| 字号 | 12 / 14 / 16 / 20 / 24（≤5 档） | 每档绑定行高，成对使用 |
| 圆角 | 2 / 4 / 8 / full | — |
| 阴影 | sm / md / lg（≤3 档） | — |
| z-index | base(0) / dropdown(100) / modal(1000) / toast(2000) | 只准用具名档位，禁止 999、99999 |
| 动效时长 | 100ms / 200ms / 300ms | 超过 300ms 的动画需要理由 |

刻度少不是限制，是目的：**一致性本身就消灭了大部分"看起来不专业"的观感**。

## 页面五态（每个页面/数据视图的必备结构）

任何消费异步数据的页面/区块，必须显式设计五种状态，缺一即结构不完整：

1. **加载中**（骨架屏或 loading 指示，禁止白屏）
2. **空数据**（有引导文案 + 下一步动作，禁止裸空白）
3. **错误**（说人话的错误信息 + 重试途径）
4. **部分数据**（列表加载更多、分页边界）
5. **理想态**

agent 默认只写理想态——所以这条不写进审美要求，写进 L2 检查和终止条件。
